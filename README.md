# CODSOFT Data Analytics Internship
This repository contains my completed tasks for the CODSOFT Data Analytics Internship.
## Tasks Completed
### Task 1: Data Cleaning
- Loaded and inspected the Superstore dataset using Pandas.
- Checked missing values and duplicate records.
- Converted order and shipping dates to date time format.
- Checked data quality and saved the cleaned dataset.

### Task 2: Exploratory Data Analysis (EDA)
- Analyzed sales and profit by category, region, and customer segment.
- Identified top-performing products.
- Examined monthly sales trends.
- Explored the relationship between discounts and profit.

### Task 3: Data Visualization
- Created charts using Matplotlib.
- Visualized category sales and profit.
- Analyzed monthly sales trends and regional performance.
- Compared sales and profit using a scatter plot.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Visual Studio Code

## Dataset
Sample Superstore dataset.

## Key Findings
- Technology generated the highest total sales and profit among the three categories.
- The West region recorded the highest total sales and profit among the four regions.
- Consumer customers contributed the highest sales among the three customer segments.
- November 2017 was the highest-sales month in the dataset.
- Some high-discount orders had negative profits, although this does not by itself establish that discounts caused the losses.
